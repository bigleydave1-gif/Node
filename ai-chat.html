    What I remember

    Saved only on this device. Nothing here is sent anywhere — it's just used to keep our conversations feeling continuous.

    🔵 Cloud connection

    Use an OpenAI-compatible chat endpoint, or your own proxy. A key stored in this browser can be exposed to anyone using this device or a public deployment — for a shared deployment, a server-side proxy is safer than a browser-stored key. No key is ever hardcoded into this app.

    Saved conversations

    Every conversation is saved on this device automatically, so you can pick up where you left off. Tap one to reload it, or delete it.

    App code

    This is this app's own HTML/CSS/JS source, read live from the file itself. You can view it, or switch to Edit to change it and save a modified copy back to this device.

    Map & GPS

    Your position comes straight from this device's real GPS chip — no internet or mobile data needed for the position fix itself. The map picture streams from OpenStreetMap and needs internet to load each area the first time. This panel floats over the chat so you can keep talking while you look at it.

    Tap "Start GPS" to get a position fix.

    Plan a route

    Pick a start and a destination. This gets a real, road-following route (not a straight line), then opens the 3D view. If GPS tracking is running, you'll get spoken turn alerts as you drive.

    Saved waypoints

    Stored on this device only — works fully offline. Tap "🧭 Route" on any waypoint to get a real road-following route from your current GPS position.

    Camera

    This uses your device's real camera. Nothing is captured until you tap the shutter — nothing is ever sent off this device.

    Crash log & rollback

    Real crashes get saved here automatically with their actual error and stack trace. Checkpoints are safe, working snapshots saved automatically each time the app starts up cleanly. Restoring a checkpoint swaps this browser tab back to that snapshot; it doesn't change the real file hosted on EdgeOne.

    Getting your assistant ready

    Downloading the AI model — this only happens once, then it's saved on this device.
