About
Athena Team Voice is a lightweight cross-platform voice client.

It can run from GitHub Pages and can be used from iPhone, iPad, Android, Windows, Mac, and modern browsers.

The actual voice audio travels through WebRTC. Supabase Realtime is used for presence and WebRTC signaling.
